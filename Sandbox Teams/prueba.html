Tipos de Listas en HTML

Listas Ordenadas

Las listas ordenadas se utilizan cuando el orden de los elementos es importante. Se pueden enumerar con números, letras o números romanos.

  1. Primer elemento
  2. Segundo elemento
  3. Tercer elemento

Listas Desordenadas

Las listas desordenadas se utilizan cuando el orden de los elementos no es relevante. Se representan con viñetas.

  • Perro
  • Gato
  • Tortuga

Listas Anidadas

Se pueden combinar listas ordenadas y desordenadas para estructurar mejor la información.

  1. Animales domésticos
    • Perro
    • Gato
  2. Animales de granja
    • Gallina
    • Vaca

Listas de Definición

Las listas de definición se utilizan para mostrar términos junto con sus descripciones.

HTML
Lenguaje de marcado utilizado para crear páginas web.
CSS
Lenguaje de estilos para diseñar páginas web.
JavaScript
